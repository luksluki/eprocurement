## What
A reusable ADR template and an index that lists every accepted decision.

## Decisions
- Template follows the same shape as ADRs 0001–0003 (context, decision, alternatives, consequences, links).
- Index links each ADR with its status and date; the process for adding a new ADR is documented in the index itself.
- README gets a CI badge now that the repository is public and Actions run on standard runners.
